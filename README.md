# UDrive2 School of Motoring — Website

Single-page website for UDrive2 School of Motoring, a driving school serving Oldham and Ashton-under-Lyne.

Plain HTML/CSS/JS — no build step. Open `index.html` locally or serve the folder from any static host.

## Structure
- `index.html` — page markup, styles and scripts
- `assets/` — logo
- `img/` — photography (WebP)

## Before launch
Placeholders marked **To supply / To confirm** need real details from the school: ADI badge number, verified reviews and Google rating, pass record, email, lesson terms, services offered and areas covered. The booking form currently prepares a text message to 07843 449 667 — connect a form service (e.g. Formspree) to receive requests directly.
